## Web 响应式设计方案

### 1. 视口设置

```html
<meta
  name="viewport"
  content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no"
/>
```

### 2. CSS 媒体查询

```css
/* 基础样式 */
.container {
  width: 100%;
  padding: 0 15px;
}

/* 平板设备 */
@media (min-width: 768px) {
  .container {
    width: 750px;
    margin: 0 auto;
  }
}

/* 桌面设备 */
@media (min-width: 992px) {
  .container {
    width: 970px;
  }
}

/* 大屏幕设备 */
@media (min-width: 1200px) {
  .container {
    width: 1170px;
  }
}
```

### 3. 弹性布局（Flexbox）

```css
.flex-container {
  display: flex;
  flex-wrap: wrap;
  justify-content: space-between;
}

.flex-item {
  flex: 0 0 100%;
}

@media (min-width: 768px) {
  .flex-item {
    flex: 0 0 calc(50% - 10px);
  }
}

@media (min-width: 992px) {
  .flex-item {
    flex: 0 0 calc(33.333% - 10px);
  }
}
```

### 4. Grid 布局

```css
.grid-container {
  display: grid;
  grid-template-columns: 1fr;
  gap: 20px;
}

@media (min-width: 768px) {
  .grid-container {
    grid-template-columns: repeat(2, 1fr);
  }
}

@media (min-width: 992px) {
  .grid-container {
    grid-template-columns: repeat(3, 1fr);
  }
}
```

### 5. 响应式图片

```html
<img src="image.jpg" alt="响应式图片" class="responsive-img" />
```

```css
.responsive-img {
  max-width: 100%;
  height: auto;
}
```

### 6. 字体响应式

```css
html {
  font-size: 16px;
}

@media (min-width: 768px) {
  html {
    font-size: 18px;
  }
}

@media (min-width: 1200px) {
  html {
    font-size: 20px;
  }
}
```

### 7. 隐藏元素

```css
.mobile-only {
  display: block;
}

.desktop-only {
  display: none;
}

@media (min-width: 768px) {
  .mobile-only {
    display: none;
  }

  .desktop-only {
    display: block;
  }
}
```

### 8. Bootstrap 响应式类

```html
<div class="container">
  <div class="row">
    <div class="col-xs-12 col-sm-6 col-md-4 col-lg-3">响应式列</div>
  </div>
</div>
```

### 9. 移动端优先原则

- 先设计移动端布局
- 使用 `min-width` 媒体查询逐步增强
- 避免使用 `max-width` 导致代码冗余

### 10. 测试工具

- Chrome DevTools 设备模拟
- BrowserStack 跨平台测试
- 真实设备测试

### 11. SCSS 自动响应式布局方案

使用 SCSS 的 `math` 模块实现自动响应式字体布局，无需手动编写多个媒体查询。

```scss
@use 'sass:math';

html {
  font-size: calc(100vw / 120);
}

@media screen and (min-width: 1800px) {
  html {
    font-size: 16px;
  }
}

@function rem($fontSize) {
  $px: $fontSize;

  @if unit($fontSize) == 'px' {
    $fontSize: math.div($fontSize, 1px);
  }

  $rem: math.div($fontSize, 16);

  @return min(#{$rem}rem, #{$px});
}

.title {
  color: red;
  font-size: rem(60px);
}
```

**原理说明：**

1. **动态根字体大小**：`calc(100vw / 120)` 使得根字体大小随视口宽度自动变化
2. **最大字体限制**：当屏幕宽度超过 1800px 时，字体大小固定为 16px
3. **rem 函数**：自动将 px 转换为 rem，并使用 `min()` 函数确保不超过原始 px 值
4. **响应式效果**：`.title` 的字体大小会在 `60px` 到 `3.75rem` 之间自动适配

### 总结

响应式设计的核心是使用灵活的网格布局、弹性图片和媒体查询，确保网站在各种设备上都能提供良好的用户体验。
